# Operação Liberta 2027

Página responsiva e interativa para acompanhar o cenário do Vasco na Libertadores de 2027.

- Site: https://filipemassi.github.io/projeto02/
- Fonte: `index.html`
- Deploy: GitHub Actions, workflow `.github/workflows/deploy.yml`
- Dados-base: 16/11/2026; este é um retrato histórico, não uma tabela ao vivo.
- Checklist salvo localmente no navegador de cada visitante.

## Publicação

No repositório, abra **Settings → Pages → Build and deployment → Source** e selecione **GitHub Actions**. O workflow publicará a página em cada alteração na branch `main`. Se o GitHub Pages ainda não estiver habilitado, essa etapa administrativa é necessária.

## Observações

A página apresenta cenários de torcida, não resultados oficiais nem probabilidades atualizadas em tempo real. Consulte as fontes citadas no rodapé antes de compartilhar novos prognósticos.
